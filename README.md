A clean, responsive, and modern personal portfolio & interactive resume website built for **Yogita Rewasia**, Data Analyst and Finance Executive.

🌐 **Live Website:** [https://yogitaanya-jpg.github.io/yogita-rewasia-portfolio/](https://yogitaanya-jpg.github.io/yogita-rewasia-portfolio/)

---

## 📌 Features

- **Responsive & Clean UI:** Designed with a modern slate & indigo palette, typography via Plus Jakarta Sans, and glassmorphic cards.
- **Dark & Light Mode:** Seamless theme switcher with persistent local storage and automatic system color preference detection.
- **Interactive Experience Timeline:** Detailed career history across Cognizant, Asha and Pragati NGO, and Educational institutions.
- **Visual Competency Matrix:** Interactive progress bars and skill cloud showcasing Microsoft Excel, Data Analytics, Financial Auditing, and Team Management.
- **Print & PDF Export:** Dedicated `@media print` CSS layout allowing users to generate a clean, professional 1-2 page printable resume with one click.
- **Direct Contact Integrations:** Quick copy-to-clipboard actions for email and phone number, direct calling, and interactive message form.
